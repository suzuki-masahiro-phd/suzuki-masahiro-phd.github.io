# Easy-edit version using Pages CMS

Upload everything in this package to the root of your GitHub Pages repository.
Keep your existing `CNAME` file.

After upload:
1. Visit https://app.pagescms.org
2. Sign in with GitHub.
3. Install/authorize Pages CMS for the `suzuki-masahiro-phd.github.io` repository.
4. Open the repository.
5. Choose **Homepage**.
6. Edit fields and save.

The website reads its content from `data/site.json`, so normal content edits do not require touching `index.html`.
